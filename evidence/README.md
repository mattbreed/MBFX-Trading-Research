## Supporting Dataset

[View the full research dataset](../evidence/merged_setups.csv)

This original Python-generated dataset contains 481 research records across 800+ columns, covering the different stages of potential trading opportunities.

The fields include identification information, detection decisions, validation results, entry conditions, simulated execution outcomes and additional research measurements. Not every record progressed to a completed trade. Some were rejected or stopped at earlier stages, so certain fields were not expected to contain results.

I've included the full dataset to demonstrate the scale of the data collection and analysis process, rather than reducing it to a handful of selected columns.
